1. 전문가가 알아야 할 사항 · 1-3 무결성
●  07

시험의 무결성은 원칙을 지키는 것부터 시작합니다.

응시자도, 출판사도 AI를 활용해서 예상문제를 뽑고 공부합니다. 우리가 넘기는 자료가 학습에 활용되면, 향후 AI는 문제은행의 자료를 응시자에게 제공할 것입니다.

입력 금지

비공개 출제자료는 외부 LLM 입력 금지입니다.

문항개발가이드·출제기준·비공개 기출문항

실제 문항, 정답, 해설, 채점기준, 난이도표

응시자 답안·개인정보, 내부 검토의견, 회의자료

국가기술자격법 제25조의2·제26조: 직무상 알게 된 검정 비밀 누설은 2년 이하 징역 또는 2천만원 이하 벌금 대상이 될 수 있습니다.
최소 조건

Opt-out(학습 사용 거부)은 최소 조건입니다.

공개 법령·가이드라인·보도자료만 제한 사용

식별 정보와 실제 문항을 제거한 추상 예시만 입력

Data Controls에서 모델 개선 사용 OFF 확인

ZDR·MAM·Enterprise·DPA 등 계약상 통제 확인

Opt-out(입력 데이터를 모델 개선·학습에 쓰지 않도록 끄는 설정)은 최소 조건일 뿐, 기존 입력·로그·파일 저장·검토 노출까지 100% 제거하는 장치는 아닙니다.
법령·사례

법적 리스크는 “외부 전송”에서 시작됩니다.

[법령] 부정경쟁방지법 제2조·제18조: 비공지 출제자료가 영업비밀이면 외국 사용·누설 시 15년 이하 또는 15억원 이하 가능

[법령] 개인정보보호법 제17·18·28조의8·70~73: 응시자 정보·답안의 동의 없는 제공·국외이전은 형사·행정 책임

[판례] 대법원 2025도11906: 상대방의 실제 사용·공모와 무관하게 넘겨주는 행위 자체가 문제

[사례] 이루다 1억330만·OpenAI 360만 처분: AI 학습·해외 AI 서비스에도 개인정보위 제재가 현실화

“AI가 처리했다”는 설명은 면책 사유가 아닙니다. 공개 공공자료가 아니면 입력하지 않는 것이 원칙입니다.
